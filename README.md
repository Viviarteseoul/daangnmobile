# 🥕 당근모바일 (Daangn Mobile)

> **우리 동네 가장 투명하고 빠른 공식인증 휴대폰 판매점**  
> 당근 공식 디자인 시스템(**SEED Design System**) 및 공식 아이콘(**`@karrotmarket/react-monochrome-icon`**) 기반 모바일 퍼스트 웹 서비스

---

## 🌟 핵심 기능 및 특징

1. **🥕 당근 순정 UI/UX & 모바일 퍼스트 인터랙션**
   - 당근마켓 피드 리스트 및 둥근 사각 썸네일, 지원금 태그, 관심 하트, 매너온도(`99.0℃ 🥕`)
   - 하단 5대 고정 탭바 (홈 / 당근특가 / 1:1 상담 / 내 신청 / 대리점 전산)
   - 실시간 기획전 드롭다운 (아이폰 18 사전예약, 전국 특가 성지, 갤럭시 S24 울트라 등)

2. **💡 실시간 요금 계산기 & 최적 혜택 비교 바텀시트**
   - **공시지원금(기기값 즉시할인) vs 선택약정 25%(매월 통신요금 할인)** 실시간 24개월 시뮬레이션
   - 출고가, 공시지원금, 당근 단독 추가지원금, 최종 할부원금 및 월 청구액 투명 제공

3. **📝 3분 비대면 온라인 간편 신청 퍼널**
   - PASS 앱 간편인증 및 휴대폰 SMS 3분 타이머 본인인증
   - 가입 유형(번호이동 / 기기변경 / 신규가입) 및 요금제 선택
   - 당일 안심 퀵 (수도권 무료) / 전국 우체국 택배 / 매장 수령 선택
   - 고유 접수번호(`DG-260819-xxxx`) 생성 및 실시간 접수증 발급

4. **💬 실시간 1:1 당근 상담 채팅창**
   - 상단 단말기 고정 바 및 `[바로 신청]` 연동
   - 퀵 질문 칩 및 실시간 인터랙티브 상담 챗봇 지원

5. **🛡️ 4대 법적/신뢰 필수 요건 100% 연동**
   - **KAIT 온라인 사전승낙서**: 협회 공인 인증 승낙번호(`2026-KAIT-DG8920`) 팝업
   - **SGI 서울보증보험**: 5,000만 원 여신 안심 담보 설정 완료
   - **통신 3사 개통 전산 심사 콘솔**: 접수 ➡️ 전산심사 ➡️ 개통승인 ➡️ 배송 ➡️ 개통완료 파이프라인
   - **내 신청 조회**: 접수번호/연락처로 실시간 개통 진행 현황 조회

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Design System**: SEED Design System (`@seed-design/react`, `@seed-design/css`)
- **Iconography**: Karrot Monochrome Icons (`@karrotmarket/react-monochrome-icon`)
- **Styling**: Tailwind CSS v4 & Pretendard Typography
